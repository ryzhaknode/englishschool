# English 30 — школа англійської для айтішника

Особистий застосунок (PWA) для 30-хвилинних уроків англійської: план, граматика, промпти для Claude і трекер прогресу.
Прогрес зберігається в безкоштовній базі **Supabase**, хостинг — безкоштовний **GitHub Pages**.
На телефоні застосунок встановлюється іконкою на головний екран і відкривається навіть без інтернету.

```
english-school-app/
├── index.html            # сам застосунок
├── config.js             # ключі Supabase (заповнюєш ти)
├── schema.sql            # таблиця прогресу + правила доступу
├── manifest.webmanifest  # назва та іконки для встановлення на телефон
├── sw.js                 # офлайн-режим
└── icons/                # іконки
```

Загалом ~20 хвилин. Кроки 1–2 налаштовують базу, 3–4 публікують сайт, 5–6 ставлять на телефон.

---

## 1. Створи базу в Supabase

1. Зайди на **supabase.com** → **Start your project** → увійди через GitHub (зручно, бо GitHub знадобиться далі).
2. **New project**:
   - Name: `english-school`
   - Database password: згенеруй і збережи в менеджері паролів (застосунку він не потрібен).
   - Region: **Central EU (Frankfurt)** — найближче до України.
   - Plan: **Free**.
3. Зачекай 1–2 хвилини, поки проєкт створиться.
4. Зліва **SQL Editor** → **New query** → встав увесь вміст `schema.sql` → **Run**. Має з'явитися «Success. No rows returned».

> Безкоштовний проєкт Supabase «засинає» після 7 днів без жодних запитів. Якщо займаєшся щодня, цього не станеться. Якщо таки заснув — у панелі Supabase натисни **Restore project**.

## 2. Скопіюй ключі в config.js

1. У Supabase: **Project Settings** (шестерня) → **API** (або **Data API** / **API Keys**).
2. Скопіюй **Project URL** і ключ **anon public** (у новому інтерфейсі він може називатися **publishable**).
3. Відкрий `config.js` і встав їх у лапки:

```js
window.SCHOOL_CONFIG = {
  SUPABASE_URL: "https://abcdefghijkl.supabase.co",
  SUPABASE_ANON_KEY: "eyJhbGciOi...довгий ключ..."
};
```

> Це публічний ключ, його нормально класти в код сайту: дані захищені правилами RLS із `schema.sql` — кожен бачить лише свої рядки.
> **Ніколи** не клади в код ключ `service_role` / `secret`.

## 3. Завантаж код на GitHub

Варіант без терміналу:
1. **github.com** → **New repository** → Name: `englishschool` → **Public** → **Create repository**.
2. На сторінці репозиторію: **uploading an existing file** → перетягни **вміст** папки `english-school-app` (усі файли й папку `icons`) → **Commit changes**.

Варіант через Git (добра практика):
```bash
cd english-school-app
git init
git add .
git commit -m "feat: english school PWA"
git branch -M main
git remote add origin https://github.com/ryzhaknode/englishschool.git
git push -u origin main
```

## 4. Увімкни GitHub Pages

1. У репозиторії: **Settings** → **Pages**.
2. **Source**: Deploy from a branch → Branch: **main**, папка **/ (root)** → **Save**.
3. Через 1–2 хвилини вгорі з'явиться адреса: `https://ryzhaknode.github.io/englishschool/`.
4. Відкрий її на ПК — має з'явитися школа з трекером.

## 5. Налаштуй вхід

1. У Supabase: **Authentication** → **URL Configuration** → **Site URL**: встав свою адресу з кроку 4 → **Save**.
2. Відкрий свій сайт → у трекері введи email і пароль → **Створити акаунт**.
3. Прийде лист від Supabase — натисни посилання підтвердження. Потім на сайті натисни **Увійти**.
   (Якщо лист не хочеш чекати: **Authentication** → **Sign In / Providers** → **Email** → вимкни **Confirm email** перед створенням акаунта.)
4. **Закрий реєстрацію для інших:** **Authentication** → **Sign In / Providers** (або **Settings**) → вимкни **Allow new users to sign up**. Тепер увійти зможеш лише ти.
5. Відміть будь-який блок у трекері й перевір у Supabase: **Table Editor** → `progress` — там має з'явитися рядок з сьогоднішньою датою.

## 6. Встанови на телефон

- **iPhone (Safari):** відкрий адресу сайту → кнопка **Поділитися** → **На початковий екран** (Add to Home Screen).
- **Android (Chrome):** відкрий адресу → меню ⋮ → **Встановити застосунок** (або **Додати на головний екран**).

Відкрий застосунок з іконки й увійди тим самим email і паролем. Прогрес на телефоні й ПК тепер однаковий.

---

## Як це працює

- Кожна позначка спершу зберігається на пристрої, потім надсилається в Supabase. Без інтернету напис покаже «офлайн · синхронізую пізніше», і дані підуть у базу, щойно зв'язок повернеться.
- Таблиця `progress`: один рядок на день — `blocks` (4 блоки: слова, вхід, мовлення, швидкість) і `min` (5-хвилинний мінімум).
- Якщо `config.js` порожній, застосунок працює повністю офлайн і зберігає прогрес лише на пристрої.

## Як оновлювати

1. Зміни файли (або попроси Claude змінити).
2. У `sw.js` збільш версію: `english-school-v1` → `english-school-v2`, інакше телефон може показувати старий кеш.
3. Залий на GitHub (`git add . && git commit -m "..." && git push`) — Pages оновиться за 1–2 хвилини.

## Якщо щось не працює

| Симптом | Що перевірити |
|---|---|
| Немає форми входу, напис «зберігається лише на цьому пристрої» | `config.js` порожній або з помилкою в лапках |
| «помилка збереження в базі» | Чи запускав `schema.sql`; відкрий консоль браузера (F12) — там буде текст помилки |
| «Invalid login credentials» | Не підтвердив email або невірний пароль |
| На телефоні старі дані/вигляд | Збільш версію в `sw.js`, або закрий і знову відкрий застосунок |
| Сайт 404 | У Pages вибрана гілка `main` і папка `/ (root)`, `index.html` лежить у корені репозиторію |
